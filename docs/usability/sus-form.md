# System Usability Scale (SUS)

Brooke, J. (1996). SUS: a "quick and dirty" usability scale. In P. W. Jordan, B. Thomas, B. A. Weerdmeester and I. L. McClelland (Eds.), *Usability Evaluation in Industry* (pp. 189 to 194). Taylor & Francis. The SUS is free to use with this acknowledgment. The wording below is the standard version with "system" replaced by "app", a common substitution.

Participant code (no names): ________   Date: ________   Role (nurse, nursing assistant, family, other): ________

For each statement, mark one box. 1 = Strongly disagree, 5 = Strongly agree. Answer by first impression; if unsure, mark 3.

## Scoring (for the researcher)

1. Odd items (1, 3, 5, 7, 9): score = answer minus 1.
2. Even items (2, 4, 6, 8, 10): score = 5 minus answer.
3. Add the ten scores and multiply by 2.5. The result runs from 0 to 100.

About 68 is average across published studies (Sauro, 2011, *A Practical Guide to the System Usability Scale*). A SUS score is not a percentage. With fewer than about 8 participants, report each person's score and the range, not only a mean.

Every item must be answered. If one is blank, ask the participant before they leave, or mark the form incomplete and leave it out of the results.
